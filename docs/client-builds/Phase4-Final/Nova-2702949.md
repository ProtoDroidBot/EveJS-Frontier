## Meaningful client differences

This `Nova` profile is **2702949**, branch Autumn staging. It is a
separate version from the sibling nebula release profile **2703993**. Their
extracted protocol dictionaries are equal, while their resource indexes have
**32 changed payload entries, no additions/removals and 48,799 equal entries**.
Those changes cover 3 audio, 10 localization and 19 static resources, including
blueprints, jumps and the starmap cache. Equal entry counts and index byte sizes
do not establish equal contents. The [direct profile comparison](evidence/profile-comparison.json)
retains all changed paths and source hashes.

Its Frontier workflow is the Phase4 smart-assembly/base-building generation:
`frontier/base_building/client/deployment/deployment_svc.pyc:104` calls
`deploymentMgr.anchor_deployable` through `RemoteSvc`, while
`frontier/smart_assemblies/client/services/smart_assembly_svc.pyc:28/35/48`
uses the public gateway and signed encrypted-wallet online/offline
meta-transactions. The classic constructables service still references
`stationConstructableManager` and `industryManager2` for blueprint/job work.
None of these calls was executed during the audit.

Direct `frontier/beta.pyc` assignments enable range-based occlusion, compared
with False in 3640684, and retain legacy scanning-disable/barcode/UI hiding
flags. Runtime overrides and client-side flag presence are separate from
authoritative feature activation.

This profile has 375 Frontier modules, including HUD (114), CRData (46),
smart assemblies (38), industry (33), station HUD (21) and base building (9).
The newer navigation, docking-point, skillshot, status-effect, Creation and
signatures/scanning families are absent under their 3640684 package names.

The sibling release profile differs structurally in exactly four unique
modules: `dogma/const`, `eve/client/script/environment/spaceObject/corpse`,
`eve/client/script/ui/login/intromovie/ui/introvideo`, and
`eve/client/script/ui/shared/neocom/wallet/walletWnd`. This target's exact
archive hash also matches Nova2702949 packaged in both Phase4-Masstest2 and
Phase4-Masstest2.5; each occurrence retains its own installation inventory.
